# Government Guarantee Scheme MADANI 2026 (GGSM4)

**Agency:** Syarikat Jaminan Pembiayaan Perniagaan (SJPP), MOF
**Type:** Loan guarantee (bank loan)
**Official / source URL:** https://sjpp.com.my/schemes/government-guarantee-scheme-madani-2026-ggsm-4
**Source type:** Official (scheme page + GGSM4 brochure Apr 2026 https://sjpp.com.my/images/scheme-brochure/cover2/GGSM4_brochure.pdf)
**Checked:** 2026-10-10

| Field | Value |
|---|---|
| Amount | not stated – RM20,000,000 |
| Rate / cost | Bank's BLR/BFR + max 2.0%; guarantee fee 0.5–1.0% p.a. |
| Tenure | Up to 7 years |
| Ownership | Sole prop: Malaysian citizen; partnerships/LLP majority Malaysian; companies ≥51% Malaysian |
| Bumiputera only | N |
| Women only | N |
| Age | n/a |
| Minimum operating period | not stated |
| Minimum turnover | not stated |
| Other eligibility | Guarantee up to 80% (MSME focus sectors: Bumiputera, Halal, Tourism, HGHV, other priority sectors) or 70%; working capital or capex, new financing only (no refinancing); government-funded or government-incentivised financing is not eligible for the guarantee; excludes GLCs, MoF Inc., state-owned enterprises, main-board PLCs, civil-servant owners without approval |
| Sectors | All |
| Deadline | 30 Jun 2027 or until fully utilised |
| Status | Open |
| How to apply | Through participating banks; SJPP +603 2096 5000 |

## Required documents
Not published; confirm with SJPP or the participating bank.

SJPP's FAQ says applicants provide the documents required by the participating financial institution; the bank then forwards the case to SJPP.

Source: SJPP FAQ: https://sjpp.com.my/faq ; GGSM4 brochure (no document list): https://sjpp.com.my/images/scheme-brochure/cover2/GGSM4_brochure.pdf

## Notes
MSME limit RM20m; group aggregate RM50m across SJPP schemes. SMEs apply to a participating bank, which forwards the case to SJPP. Guarantee fee 0.5% p.a. where BNM funding to the bank is at 0%, 0.75% for HGHV/focus sectors, 1.0% for others.
