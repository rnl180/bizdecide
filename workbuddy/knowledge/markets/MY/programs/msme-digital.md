# MSME Digital Grant MADANI

**Agency:** BSN (disbursing) / MDEC (solution panel) / MOF
**Type:** Matching grant
**Official / source URL:** https://bsn.com.my/page/MSMEMadani
**Source type:** Official (BSN page + BSN FAQ Aug 2025 https://www.bsn.com.my/cms/upload/pdf/business/msme_faq_aug_bm.pdf; closure notice on BSN's Apply Now form https://fundingsocieties.com.my/msme-digital-grant-madani)
**Checked:** 2026-10-10

| Field | Value |
|---|---|
| Amount | RM0 – RM5,000 |
| Rate / cost | Grant: up to 50% of invoice, max RM5,000 |
| Tenure | n/a |
| Ownership | ≥60% Malaysian citizens |
| Bumiputera only | N |
| Women only | N |
| Age | n/a |
| Minimum operating period | 6 months |
| Minimum turnover | RM50,000 average annual |
| Other eligibility | Up to 3 digital services from MDEC-appointed providers (e-POS, HR/CRM, digital marketing, cybersecurity, ERP/accounting & tax, digital signature, IoT, AI, e-invoice); not for SMEs that already received an earlier Digitalisation Matching Grant (except for e-invoice services); subject to allocation |
| Sectors | All |
| Deadline | Closed: applications closed effective 6 Sep 2025 (last day 5 Sep 2025) |
| Status | Closed (official application form); no 2026 round found on BSN or MDEC pages |
| How to apply | BSN 'Apply Now' links to the MDEC-appointed Funding Societies form, which is closed |

## Required documents
- Copy of IC or passport of the sole proprietor / director / partner / appointed representative
- Copy of SSM registration (or equivalent; SKM certificate for cooperatives; statutory-body certificate for professionals)
- Latest audited accounts, OR latest management accounts, OR bank statements for the last 2 months
- Quotation or payment invoice from the appointed digital service provider
- Other documents BSN requests from time to time
- Note: applications closed on 6 Sep 2025; this list applies only if a new round opens

Source: BSN page https://bsn.com.my/page/MSMEMadani and BSN FAQ (Aug 2025) Q5: https://www.bsn.com.my/cms/upload/pdf/business/msme_faq_aug_bm.pdf
