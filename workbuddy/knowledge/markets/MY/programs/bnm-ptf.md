# PENJANA Tourism Financing (PTF)

**Agency:** Bank Negara Malaysia via participating FIs; SJPP guarantee
**Type:** Concessionary loan
**Official / source URL:** https://www.bnm.gov.my/funds4sme
**Source type:** Official
**Checked:** 2026-10-10

| Field | Value |
|---|---|
| Amount | RM0 – RM500,000 |
| Rate / cost | not stated on page |
| Tenure | not stated on page |
| Ownership | SME |
| Bumiputera only | N |
| Women only | N |
| Age | n/a |
| Minimum operating period | not stated |
| Minimum turnover | not stated |
| Other eligibility | Tourism sectors/activities listed under National Tourism Policy 2020–2030; for expansion/investment (Visit Malaysia Year 2026) |
| Sectors | Tourism |
| Deadline | not stated |
| Status | Open |
| How to apply | Participating FIs |

## Required documents
See brochure/FAQ on BNM page

## Notes
A neighbourhood kopitiam is unlikely to qualify unless tourism-linked.
